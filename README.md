# boxiong-wang.github.io

Personal academic website for Boxiong Wang.

## Public file naming

Keep public-facing filenames stable and version-free:

- Profile photo: `assets/boxiong-wang-profile.jpg`
- CV: `files/boxiong-wang-cv.pdf`
- Working papers: use lowercase descriptive filenames with hyphens, for example `papers/better-credit-review-less-aggregate-information.pdf`

When a new version of a CV or paper is uploaded, replace the existing public file rather than changing its public URL.
